> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `main` dalını tam yeşile almak: öğretmen profil güncellemesindeki 500 hatasını kalıcı olarak düzeltmek, derlenmeyen mobil testleri onarmak, geliştirmede sahte veriyi kapatmak, DB sırrını konfigürasyondan çıkarmak ve gerçek-DB testlerini yerelde koşulabilir hale getirmek.

Mobilde test sahteleri (`fake`) gerçek arayüz imzasına hizalanır, `AppConfig` mock fallback varsayılanı kapatılır. DB bağlantı dizesi `appsettings.json`'dan çıkarılıp `ConnectionStrings__Postgres` env değişkenine taşınır ve `JwtSigningKeyGuard` ile aynı desende startup guard'ı eklenir.

**Tech Stack:** .NET 9, EF Core 9 (Npgsql + InMemory), xUnit, Testcontainers, Flutter 3 / Dart, `flutter_test`, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-02-saglamlastirma-master-design.md`

`src/Modules/Teachers/Domain/TeachersDomainModel.cs` içinde `Update`'in **altına** ekle:
```csharp
    /// <summary>
    /// Branş listesini doğal anahtara (branş adı) göre birleştirir: eşleşenler korunur (PK değişmez),
    /// listede olmayanlar silinir, yeni olanlar eklenir. Sil-yeniden-ekle deseni EF'te
    /// "orphan update" hatasına yol açtığı için tercih edilmez (A-01).
    /// </summary>
    public void MergeSubjects(IReadOnlyCollection<TeacherSubject> desired)
    {
        var desiredNames = desired
            .Select(subject => subject.Subject)
            .ToHashSet(StringComparer.OrdinalIgnoreCase);

        Subjects.RemoveAll(existing => !desiredNames.Contains(existing.Subject));

        var existingNames = Subjects
            .Select(subject => subject.Subject)
            .ToHashSet(StringComparer.OrdinalIgnoreCase);

        Subjects.AddRange(desired.Where(subject => existingNames.Add(subject.Subject)));
    }

    /// <summary>
    /// Sertifikaları (Başlık, Kurum, Yıl) üçlüsüne göre birleştirir.
    /// </summary>
    public void MergeCertificates(IReadOnlyCollection<TeacherCertificate> desired)
    {
        static string Key(TeacherCertificate certificate)
            => $"{certificate.Title}|{certificate.Institution}|{certificate.Year}".ToUpperInvariant();

        var desiredKeys = desired.Select(Key).ToHashSet(StringComparer.Ordinal);
        Certificates.RemoveAll(existing => !desiredKeys.Contains(Key(existing)));

        var existingKeys = Certificates.Select(Key).ToHashSet(StringComparer.Ordinal);
        Certificates.AddRange(desired.Where(certificate => existingKeys.Add(Key(certificate))));
    }

    /// <summary>
    /// Uygunluk slotlarını (Gün, Başlangıç, Bitiş) üçlüsüne göre birleştirir; eşleşen slotta
    /// yalnız online/yüz yüze bayrakları güncellenir.
    /// </summary>
    public void MergeAvailabilitySlots(IReadOnlyCollection<TeacherAvailabilitySlot> desired)
    {
        static string Key(TeacherAvailabilitySlot slot)
            => $"{(int)slot.DayOfWeek}|{slot.StartTime:HH\\:mm}|{slot.EndTime:HH\\:mm}";

        var desiredByKey = desired.ToDictionary(Key, slot => slot, StringComparer.Ordinal);
        AvailabilitySlots.RemoveAll(existing => !desiredByKey.ContainsKey(Key(existing)));

        foreach (var existing in AvailabilitySlots)
        {
            var match = desiredByKey[Key(existing)];
            existing.SetAvailability(match.IsOnlineAvailable, match.IsInPersonAvailable);
        }

        var existingKeys = AvailabilitySlots.Select(Key).ToHashSet(StringComparer.Ordinal);
        AvailabilitySlots.AddRange(desired.Where(slot => existingKeys.Add(Key(slot))));
    }
```

- [x] **Step 5b: Çocuk entity anahtarlarını `ValueGeneratedNever()` yap** _(yürütmede eklendi — merge tek başına yetmiyor)_

> **Neden:** Merge uygulandıktan sonra da "aynı branş" senaryosu geçti ama "yeni branş ekle" senaryosu aynı
> `DbUpdateConcurrencyException` ile kaldı. `ChangeTracker` dökümü sebebi gösterdi: çocuk `Id`'leri `IIdGenerator`
> ile **istemcide** atanıyor, ama EF konvansiyonu Guid PK'yı `ValueGenerated.OnAdd` sayıyor. Bu yüzden izlenen bir
> profile eklenen yeni çocuk `Added` yerine **`Modified`** olarak izleniyor ve var olmayan satır UPDATE ediliyor.
> (Deneyle doğrulandı: `Id = Guid.Empty` verildiğinde EF `Added` işaretliyor.) Asıl kök neden budur; merge, kimliklerin
> gereksiz yere değişmesini önleyen tamamlayıcı düzeltmedir.

`src/Modules/Teachers/Infrastructure/TeachersDbContext.cs` — `teacher_subjects`, `teacher_certificates`,
`teacher_availability_slots` konfigürasyonlarında `HasKey`'in altına:
```csharp
        builder.Property(entity => entity.Id).ValueGeneratedNever();
```
Şema değişmez (Guid PK'da DB tarafı default zaten yoktu) → yeni migration gerekmez.

```csharp
namespace EgitimUssu.Shared.Infrastructure.Configuration;

/// <summary>
/// Postgres bağlantı dizesini startup'ta doğrular (JwtSigningKeyGuard ile aynı desen):
/// prod'da boş veya varsayılan/zayıf parolalı dize ile uygulama açılmaz.
/// </summary>
public static class ConnectionStringGuard
{
    private static readonly string[] WeakPasswords = ["password=postgres", "password=changeme", "password="];

    public static void Validate(string? connectionString, bool isDevelopment)
    {
        if (connectionString is not null && connectionString.StartsWith("InMemory:", StringComparison.OrdinalIgnoreCase))
        {
            return;
        }

        if (string.IsNullOrWhiteSpace(connectionString))
        {
            throw new InvalidOperationException(
                "ConnectionStrings:Postgres boş. Bağlantı dizesini ConnectionStrings__Postgres ortam değişkeniyle verin.");
        }

        if (isDevelopment)
        {
            return;
        }

        var normalized = connectionString.Replace(" ", string.Empty).ToLowerInvariant();
        foreach (var weak in WeakPasswords)
        {
            if (normalized.Contains(weak, StringComparison.Ordinal))
            {
                throw new InvalidOperationException(
                    "ConnectionStrings:Postgres varsayılan/zayıf parola içeriyor. Üretimde gerçek bir sır kullanın.");
            }
        }
    }
}
```
