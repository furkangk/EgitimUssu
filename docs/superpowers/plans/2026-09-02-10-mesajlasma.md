# P10 — Mesajlaşma (M16) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Öğretmen↔öğrenci ve öğretmen↔veli sohbetini uçtan uca çalıştırmak: yeni Messaging modülü (sohbet, mesaj, okundu, engelleme, şikayet kancası, hız sınırı) ve mobilde gelen kutusu + sohbet ekranı, yeni mesajda push.

**Architecture:** `src/Modules/Messaging` (4 katman, `messaging` şeması). `Conversation` (katılımcı çifti + öğrenci bağlamı) ve `Message` aggregate'leri. Katılımcı doğrulaması **modül sınırını korur**: öğretmen-öğrenci bağı `Shared/Contracts/IStudentDirectory`, veli-öğrenci bağı `IParentAccessDirectory` üzerinden sorulur. v1 gerçek-zamanlı değil (karar **K-07**): REST + keyset sayfalama + push bildirimi. Yeni mesaj `MessageSentIntegrationEvent` yayar; Notifications bunu tüketip alıcıya `UserNotification` + push üretir (tercih kapısı P05'ten geçer).

**Tech Stack:** .NET 9, EF Core, xUnit; Flutter (`flutter_chat_ui` zaten pubspec'te — artık gerçekten kullanılır, D-18).

**Spec:** `docs/superpowers/specs/2026-09-02-saglamlastirma-master-design.md` (karar **K-07**)

## Global Constraints

- **İzinli çiftler:** Yalnız `Teacher↔Student` ve `Teacher↔Parent`. Öğrenci↔öğrenci, veli↔veli, öğrenci↔veli **domain tarafından reddedilir** (`messaging.pair_not_allowed`).
- **İlişki zorunlu:** Taraflar arasında aktif bağ yoksa sohbet açılamaz (`messaging.relationship_required`).
- **Tek sohbet:** Aynı çift + aynı öğrenci bağlamı için tek `Conversation` (get-or-create).
- **Yumuşak silme:** Mesaj silinince içerik gizlenir (`IsDeleted`, `Body` boşaltılmaz — denetim için saklanır, API `null` döner).
- **Hız sınırı:** Kullanıcı başına dakikada 30 mesaj; aşımda `429` (`Shared` Redis rate limiter'ı yeniden kullanılır).
- **Idempotency:** Notifications tarafındaki tüketici `IdempotentIntegrationEventHandler`.
- **Migration:** `dotnet ef migrations add <Ad> --project src/Modules/Messaging/Infrastructure --startup-project src/API.Host --context MessagingDbContext`
- **Commit:** Conventional Commits, görev başına bir commit.
