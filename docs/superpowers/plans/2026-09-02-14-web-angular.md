# P14 — Angular Web (Admin Paneli + Public Keşif) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web platformunu açmak: önce **admin paneli** (moderasyon, kullanıcı yönetimi, doğrulama, üyelik/plan, raporlar), ardından **public keşif** sayfaları (öğretmen arama + public profil, SEO'ya açık) — mevcut backend API'lerini tüketerek.

**Architecture:** `web/` altında Angular 20 workspace; standalone component'ler, signals tabanlı state, `provideRouter` ile lazy-loaded feature rotaları, `HttpInterceptor` ile JWT + sessiz refresh (mobildeki `TokenRefreshInterceptor` mantığının eşleniği). Tasarım token'ları `doc/architecture/design_system.md`'den SCSS değişkenlerine birebir aktarılır — mobil ile aynı renk/tipografi/spacing ölçeği. Admin paneli `/api/admin/*` (P12) uçlarını, public keşif `/api/matching/*` + `/api/reviews/*` (P11) uçlarını tüketir. Public sayfalar SSR (Angular SSR) ile sunulur ki arama motorları içeriği görebilsin.

**Tech Stack:** Angular 20 (standalone + signals), TypeScript 5, SCSS, Angular SSR, Vitest/Karma + Playwright (e2e), Node 22.

**Spec:** `docs/superpowers/specs/2026-09-02-saglamlastirma-master-design.md` (karar **K-11**)

## Global Constraints

- **Önkoşul:** P11 (keşif/yorum uçları) ve P12 (admin uçları) tamamlanmış olmalı. Backend'e bu planda **yeni uç eklenmez**; eksik uç çıkarsa ilgili plana geri dönülür.
- **Tek tasarım kaynağı:** Renk/tipografi/spacing `doc/architecture/design_system.md`. Yeni token icat edilmez; ana renk `#082B4F`.
- **Türkçe:** Tüm kullanıcıya görünen metinler Türkçe ve **tam Türkçe karakterli**; görünen ad `EğitimÜssü`, kod/dosya adı `EgitimUssu`.
- **Güvenlik:** Token `localStorage`'a **yazılmaz**; access token bellekte, refresh token `httpOnly` çerez yerine — bu mümkün değilse `sessionStorage` + kısa ömür. Admin paneli yalnız `Admin` rolüne açılır; rol kontrolü hem route guard hem sunucu tarafında (API zaten 403 döner).
- **Public sayfalarda PII yok:** Öğretmen public profilinde telefon/e-posta gösterilmez (API zaten dönmez; UI de talep etmez).
- **Erişilebilirlik:** `doc/architecture/accessibility.md` kuralları: klavye ile tam gezinme, kontrast AA, form alanlarında `label`.
- **Commit:** Conventional Commits, görev başına bir commit.
